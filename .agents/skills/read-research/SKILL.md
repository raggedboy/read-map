# Read Research

Read `AGENTS.md` and `map/AGENTS.md` completely. Keep the repository unchanged.

1. State the reading goal and inspect existing readings to avoid duplicate discovery.
2. Identify every candidate exactly: title, author or owner, material type, canonical link, version when material, and concrete value for the goal.
3. Verify claims from primary or canonical sources. Judge the material itself, not its age by a fixed rule.
4. Conclude only `推荐` or `不推荐`. When evidence is insufficient, present verified facts and the exact uncertainty, then ask the user to decide instead of manufacturing a rating.

Do not add candidates to inbox. Finish when each candidate has a supported conclusion or a clearly stated user decision.
